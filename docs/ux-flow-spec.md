# Alpha Plus driver UX flow

The reference package was reviewed as an interaction and sizing guide. Alpha
Plus keeps AlphaRide branding, original assets, operational rules, and copy.

## End-to-end journey

1. Splash, phone authentication, OTP, and optional biometrics
2. Driver identity, service type, vehicle, licence, and document capture
3. Verification review and device setup
4. Map dashboard with durable online/offline availability
5. New-ride offer with fare, distance, class, payment, and route
6. Pickup navigation, passenger call, and arrival
7. Waiting meter, trip start, live route, and fare status
8. Completion confirmation and receipt handoff
9. Trip history, money, prepaid wallet, pool, inbox, profile, and support

## Shared visual contract

- 16 dp page and sheet padding
- 48 dp minimum interactive controls
- 56 dp primary actions
- 14 dp controls, 20 dp cards, and 24 dp modal sheets
- 48 by 5 dp sheet handle
- matching light/dark semantic colors and legible status states
- preserved call controls, wallet enforcement, and ride lifecycle behavior
